# ☁️ TCloud Drive

### Transforme sua conta do Telegram em uma nuvem organizada para seus arquivos.

O **TCloud Drive** é uma ferramenta para Windows que facilita o armazenamento e a organização de arquivos utilizando sua própria conta do Telegram.

Com uma interface semelhante ao **Windows Explorer**, você pode organizar, enviar e baixar seus arquivos e pastas de maneira simples.

## 🚀 Principais recursos

- 📁 Envio de arquivos e pastas completas
- 📥 Download de arquivos e pastas
- 🗂️ Organização em pastas
- 🖥️ Interface semelhante ao Windows Explorer
- 🔄 Mantém a estrutura das pastas
- 🖼️ Visualização e organização dos arquivos
- ☁️ Arquivos armazenados na sua própria conta do Telegram
- 🔐 Seus arquivos permanecem vinculados à sua conta

## ⚠️ Aviso

O **TCloud Drive é um projeto independente** e não possui vínculo oficial com o Telegram.

O armazenamento e a disponibilidade dos arquivos dependem dos serviços fornecidos pelo Telegram.
